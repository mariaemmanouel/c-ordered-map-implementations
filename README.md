ΑΣΚΗΣΗ 1:

Για όλες τις συναρτήσεις χρησιμοποίησα την υλοποίηση του ADT Map χρησιμοποιώντας Set που βρίσκεται στο lecture-code, αλλά την άλλαξα ώστε να πληρεί το interface του Ordered Map και όχι του απλού Map. Για τη συνάρτηση omap_last χρησιμοποίησα ως πρότυπο την omap_first και απλά άλλαξα το set_first σε set_last και για τη συνάρτηση omap_previous χρησιμοποίησα ως πρότυπο την omap_next και απλά άλλαξα το set_next σε set_previous

| ΣΥΝΑΡΤΗΣΗ | ΠΟΛΥΠΛΟΚΟΤΗΤΑ | ΕΠΕΞΗΓΗΣΗ |
| :---: | :---: | :---: |
| omap_create | $O(1)$ | Δεσμεύει σταθερή μνήμη και αρχικοποιεί ένα κενό Set |
| omap_size | $O(1)$ | Απλή επιστροφή του size του Set |
| omap_find | $O(logn)$ | Εκτελεί αναζήτηση στο ισοζυγισμένο δέντρο |
| omap_insert | $O(logn)$ | Κάνει αναζήτηση και αν το κλειδί δεν υπάρχει κάνει εισαγωγή και αναδιοργάνωση του δέντρου |
| omap_remove | $O(logn)$ | Εντοπίζει τον κόμβο και τον διαγράφει, προκαλώντας αναδιοργάνωση του δέντρου |
| omap_set_destroy_key | $O(1)$ | Απλά θέτει την νέα συνάρτηση καταστροφής κλειδιών σε μια μεταβλητή της δομής |
| omap_destroy | $O(n)$ | Διατρέχει όλους τους κόμβους και τους καταστρέφει |
| omap_first | $O(logn)$ | Αναζητά το ελάχιστο στοιχείο ξεκινώντας από τη ρίζα και ακολουθώντας τους αριστερούς δείκτες |
| omap_last | $O(logn)$ | Αναζητά το μέγιστο στοιχείο ξεκινώντας από τη ρίζα και ακολουθώντας τους δεξιούς δείκτες |
| omap_next | $O(logn)$ | Αναζητά τον κόμβο στο Set και μετά τον επόμενο |
| omap_previous | $O(logn)$ | Αναζητά τον κόμβο στο Set και μετά τον προηγούμενο |
| omap_find_node | $O(logn)$ | Εκτελεί δυαδική αναζήτηση στο Set για να βρει και να επιστρέψει τον κόμβο |
| omap_node_key | $O(1)$ | Απλή επιστροφή του key |
| omap_node_value | $O(1)$ | Απλή επιστροφή του value |
